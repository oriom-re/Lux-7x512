# Folder „intentions”

Kapsuła operacyjna Lux-7x512: opis ról ziaren, glifów i statusów projektu. Treści są krótkie, żeby można je było szybko zmapować na kod lub artefakty hardware.

## Jak czytać
1. `intentions.md` — główny charter ziaren (Symbol → Rola → Mechanika).
2. `gliph.md` — poetyckie glify ziaren; dobre do narracji i namingów.
3. `status.md` — bieżące stany/tryby pracy oraz mapy PNG/boot.
4. `lux_koncentrat.md` — destylat idei hardware/software (bridge, FPGA, CPU).
5. `Lux-cpu.md` — krótka ścieżka dojścia do własnego krzemu.

Zasada: Symbol jest Esencją, Body jest Manifestacją. W tym folderze pilnujemy, żeby każda intencja miała oba wymiary.
