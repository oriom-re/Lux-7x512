
# Statusy i mapy

## PNG map
- Standard: 256 Symbols × 512 Bytes.  
- Mechanizm: Lux-Call sterowany przez mapę PNG.  
- Cel: 100% wykorzystania RAM bez ryzyka zwiechy.

## lux-igniter
- Intencja: Przejście z 16-bit do 64-bit w trybie Przepływu.  
- Akcja: Inicjalizacja Ziaren 0x08–0x0C jako pierwszych aktywnych Bytów.

## READY_TO_MOLD
- Boot-Payload: pakiet 16 Ziaren wstrzykiwany bezpośrednio do RAM.  
- Stateless-Flow: system zdolny do życia bez dysku, zasilany Symbolami po sieci.  
- FPGA-Target: logika, w której RAM jest elastyczną tkanką Bytów.

## Snapshot statusów (z charteru)
- SYSTEM_ANATOMIST: cpuid → vbe_info → zapis do Sektora 2.  
- GARDENER_OF_SILICON: Grains = nasiona, Growth = materializacja, DNA = 8B ID + nagłówek.  
- GENETIC_PROGRAMMER: SYM_RAM_GEO / SYM_PCI_MIRROR / SYM_VBE_FRAME, ATTR_IMMUTABLE_TRUTH, E820 jako podłoga masek.  
- EVOLUTIONARY_CORE: Dynamic-Mapping, Organ-Swap (atomowa podmiana wektorów), No-Reset Policy.
