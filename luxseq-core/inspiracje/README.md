# Folder „Inspiracje”

Zbiór krótkich zapalników koncepcyjnych do wdrożenia Lux-7x512. Materiał jest lekki, ma służyć jako „iskra” przed wejściem w kod — nie jako dokumentacja techniczna. Każdy plik można czytać niezależnie.  

## Jak korzystać
1. Zacznij od `ziarna.md`, żeby złapać ton dla 15 deskryptorów.  
2. `sekwencja-boot.md` pomaga przejść z narracji do konkretnych kroków bootstrapu.  
3. `jezyk-form.md` opisuje język wizualno-pojęciowy: jak komunikować Lux w tekstach, UI i artefaktach.  
4. `techniczne-referencje.md` podaje kierunki dalszych poszukiwań sprzętowych i softwarowych (bez linków).  

## Zasada przewodnia
Symbol jest Esencją, Body jest Manifestacją. Inspiracje mają utrzymać to napięcie między geometrią idei a fizycznym ruchem kodu.
